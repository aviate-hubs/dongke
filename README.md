# 动课 dongke

> 让知识动起来 —— 面向中国 K12 的互动可视化课件，打开就能上课。

## 这是什么

动课是一套给中小学老师**直接在课堂上用**的互动可视化课件。

抽象的概念（函数图像怎么随参数变化、光怎么折射、分子怎么运动、地球为什么有四季）往往一句话讲不清，一张静态图也看不明白。动课把这些知识点做成可以拖动、调节、播放的互动页面，老师在大屏上演示，学生看得见、摸得着。

## 设计原则

- **打开即用**：浏览器打开就能上课，不用安装、不用注册
- **贴合教材**：按学科、年级、教材章节组织，对齐国家课程标准
- **为课堂设计**：适配教室投屏和触控一体机，字大、对比强、操作简单
- **一课一知识点**：每节动课只讲清楚一件事，方便嵌入老师自己的教学流程
